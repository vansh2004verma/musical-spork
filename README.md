# musical-spork
A drum kit made by using basic html,css and javascript 

🛠️ Explanation:
The switch statement checks the key pressed or button clicked.

Depending on the key (w, a, s, etc.), it creates an Audio object with the corresponding sound file.

.play() plays the sound.

If an undefined key is pressed, it logs the key to the console.





🎯 How the Code Works Together:
Click a Button:

A button is clicked → makeSound() plays the sound → buttonAnimation() shows animation.
Press a Key:

A key is pressed → makeSound() plays the sound → buttonAnimation() shows animation.
Dynamic Behavior:

The switch statement maps each button/key to the correct sound file.
